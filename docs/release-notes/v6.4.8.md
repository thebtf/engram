# Engram v6.4.8 - Codex Plugin MCP Root Fix

> Published: 2026-06-03

Engram v6.4.8 is a Codex plugin patch release for Desktop Codex sessions that
still failed MCP startup after updating to v6.4.7.

## What changed

- `.mcp.json` now launches `scripts/run-engram.js` through Codex's
  `${CLAUDE_PLUGIN_ROOT}` interpolation.
- The plugin no longer depends on `PLUGIN_ROOT` being present in the MCP child
  process environment.
- The wrapper is no longer resolved from the workspace `cwd`, which could point
  at the project directory instead of the installed plugin cache.
- The source daemon version now reports `v6.4.8`, with a regression test tying
  it to both Codex and Claude plugin manifest versions.

## Upgrade note

Upgrade the Engram marketplace and reinstall the plugin. A fresh Desktop Codex
thread should then start the MCP server from the installed plugin cache rather
than the workspace directory.
