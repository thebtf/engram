# Engram v6.4.11 - Codex Muxcore Stale Daemon Guard

Engram v6.4.11 hardens the local stdio MCP client startup path for Desktop
Codex plugin installs.

## Fixed

- The muxcore daemon marker now records the executable path in addition to the
  daemon version and PID.
- Startup now treats same-version markers from a different `engram.exe` path as
  stale, so a release-smoke or older plugin-data daemon cannot silently keep the
  global `engram-muxd.ctl.sock` owner slot.
- Added regression coverage for legacy markers, markers without executable path,
  matching executable markers, and different executable markers.

## Operator Notes

- This release does not change the Codex plugin environment contract:
  `ENGRAM_URL` and `ENGRAM_TOKEN` are still forwarded through Codex stdio MCP
  `env_vars` / `shell_environment_policy.set`.
- If Desktop Codex still reports an MCP startup failure after installing this
  release, inspect `%TEMP%\engram-muxd.ctl.sock.version` and the plugin data
  diagnostics log before editing Codex config.
