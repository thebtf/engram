# Engram v7.0.18

Privacy-only corrective release for project memory search (issue 532).

## Fixed

- Authorize candidates using the actual REST/MCP caller before lexical, literal, vector or graph ranking and limits. Recheck lifecycle, identity and current access before sending memory bodies to the configured reranker or returning results.
- Bind selected versions to their UTF-8 body digests and reject conflicting lexical/vector identities before fusion credit or candidate caps.
- Preserve semantic search after authorized full-text search falls back to OR. Keep partial-match provenance, literal/tag recovery, visible reranking and bounded graph expansion; do not treat a weak rank-one OR match as a strict match.

## Upgrade notes

- Update the server and plugins through their ordinary release channels. The owner's Unraid repository remains `ghcr.io/thebtf/engram:latest`; do not replace it with a digest or version pin.
- This patch adds no schema migration, data rewrite, identity change, configuration variable or OpenClaw host upgrade. Preserve existing data, history, privacy settings and recovery inputs.
- Publication and installation are separate from source proof. Check the actual server/client/plugin versions and the ordinary authenticated search path after delivery; an older running server does not gain this fix from a plugin version change alone.
- Feature 513 and the separate effective-task-context A/B changes are not part of this patch.
