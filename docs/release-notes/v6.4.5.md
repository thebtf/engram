# Engram v6.4.5 - Codex Marketplace Launch Path Fix

> Published: 2026-06-03

Engram v6.4.5 is a Codex plugin patch release. It fixes the marketplace install
path where Desktop Codex could register `engram@engram-marketplace` but fail the
MCP handshake before tools were available.

## What changed

- Codex MCP launch now starts from the installed plugin root via `cwd: "."`.
- The wrapper can infer Codex plugin data storage from the cache path when
  `PLUGIN_DATA` is absent.
- Hook modules are import-safe under `node --test`, keeping plugin regression
  tests runnable.

## Operator impact

After updating the marketplace and reinstalling or updating the plugin, Codex
should create a new `engram@engram-marketplace` cache slot for `6.4.5`. Existing
`6.4.4` installs can keep the old launcher until the plugin is refreshed.
