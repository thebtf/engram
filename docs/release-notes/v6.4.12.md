# Engram v6.4.12 - Codex Direct gRPC Backend Connections

Engram v6.4.12 fixes a Desktop Codex startup path where the plugin-installed
client initialized successfully but exposed only local tools because backend
gRPC calls were routed through a blocked proxy endpoint.

## Fixed

- The local MCP daemon now disables proxy use for Engram backend gRPC
  connections.
- `engramcore` remote tool discovery now connects directly to `ENGRAM_URL`
  during `tools/list`.
- The serverevents bridge now uses the same direct backend connection behavior
  for project event streams and heartbeat reconciliation.

## Verification

- `go test ./internal/handlers/engramcore ./internal/handlers/serverevents`
- `go test ./...`
- `go build -o .agent/tmp/engram-v6.4.12-smoke.exe ./cmd/engram`
- `D:\Dev\mcp-launcher\mcp-launcher.exe -mode call -binary D:\Dev\engram\.agent\tmp\engram-v6.4.12-smoke.exe -cwd D:\Dev\engram -method tools/list -expect-version v6.4.12 -expect-tools 44 -timeout 120`

## Operator Notes

- This release does not change the required Codex configuration keys:
  `ENGRAM_URL` and `ENGRAM_TOKEN`.
- If a workstation still has an older plugin data binary after reinstall,
  upgrade/reinstall the plugin so the persistent plugin data directory downloads
  the `v6.4.12` client binary.
