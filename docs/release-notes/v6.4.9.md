# Engram v6.4.9

Patch release for Codex local marketplace install hygiene.

## Fixed

- Added a tracked `.agents/plugins/marketplace.json` so
  `codex plugin marketplace add <repo-root>` works from a clean checkout.
- Aligned the repo-local marketplace name with the published
  `engram-marketplace` identity to avoid creating a duplicate
  `engram@engram` local plugin with stale data/cache state.
- Bumped plugin and daemon version metadata to `6.4.9` so Codex consumers pick
  up the marketplace correction as new plugin content.
