# Engram v6.4.10 - Codex Startup Diagnostics

> Published: 2026-06-03

Engram v6.4.10 is a Codex plugin patch for the Desktop Codex MCP startup
failure where the plugin was installed but `engram` tools never appeared.

## What changed

- The Codex/Claude wrapper now writes a redacted startup environment diagnostic
  to stderr and `pluginData/logs/startup-env.log`.
- The diagnostic reports whether `ENGRAM_URL` and `ENGRAM_TOKEN` reached the MCP
  child as `present`, `missing`, `empty`, or `placeholder`. Token values are
  never logged.
- `ensure-binary.js` now tolerates Windows `EPERM` from Node's piped
  `engram.exe --version` probe when the `.version` marker already matches and
  the executable can still start with ignored stdio. This stops repeated
  download attempts for an already-current binary while keeping stale-marker
  protection.

## Operator impact

After upgrading and starting a fresh Codex thread, inspect:

```text
%USERPROFILE%\.codex\plugins\data\engram-marketplace-engram\logs\startup-env.log
```

If the log shows `ENGRAM_URL=present` and `ENGRAM_TOKEN=redacted(...)`, the
workstation configuration reached the plugin child and the remaining failure is
below env forwarding. If either value is `missing`, `empty`, or `placeholder`,
fix the Codex environment/config path before debugging the Engram server.
