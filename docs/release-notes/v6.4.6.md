# Engram v6.4.6 - Codex MCP Entrypoint Fix

> Published: 2026-06-03

Engram v6.4.6 is a Codex plugin patch release for the MCP startup failure seen
after installing v6.4.5.

## What changed

- The Codex `.mcp.json` `node -e` bootstrap now calls the exported
  `run-engram.js` `main()` function.
- `run-engram.js` exports `main` for the bootstrap path while preserving direct
  script execution.
- Plugin tests now execute the exact `.mcp.json` eval entrypoint against a fake
  wrapper and fail if it only imports the file without starting it.

## Operator impact

Users who installed v6.4.5 should upgrade the `engram-marketplace` snapshot and
refresh/reinstall the plugin so Codex creates or switches to the `6.4.6` cache
slot. The required workstation configuration is unchanged: `ENGRAM_URL` and
`ENGRAM_TOKEN` must be present in Codex `~/.codex/config.toml` under
`[shell_environment_policy.set]`.
