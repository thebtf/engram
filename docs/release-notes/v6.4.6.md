# Engram v6.4.6 - Codex MCP Startup Fixes

> Published: 2026-06-03

Engram v6.4.6 is a Codex plugin patch release for the MCP startup failure seen
after installing v6.4.5 and for stale local daemon reuse after binary upgrades.

## What changed

- The Codex `.mcp.json` `node -e` bootstrap now calls the exported
  `run-engram.js` `main()` function.
- `run-engram.js` exports `main` for the bootstrap path while preserving direct
  script execution.
- The local client now stops an older embedded muxcore daemon before connecting
  when the daemon version marker is missing or differs from the current binary.
  This prevents `initialize.serverInfo.version` from staying on stale values
  such as `v5.0.0` after a plugin/binary upgrade.
- The release-binary workflow now smokes MCP `initialize.serverInfo.version` for
  the Linux release asset, in addition to `engram --version`.
- Plugin tests now execute the exact `.mcp.json` eval entrypoint against a fake
  wrapper and fail if it only imports the file without starting it.

## Operator impact

Users who installed v6.4.5 should upgrade the `engram-marketplace` snapshot and
refresh/reinstall the plugin so Codex creates or switches to the `6.4.6` cache
slot. On first use, the new client may log that it stopped a stale muxcore
daemon; subsequent starts should reuse the fresh daemon normally. The required
workstation configuration is unchanged: `ENGRAM_URL` and `ENGRAM_TOKEN` must be
present in Codex `~/.codex/config.toml` under `[shell_environment_policy.set]`.
