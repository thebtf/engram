# Engram v6.4.7 - Codex Plugin Binary Refresh Fix

> Published: 2026-06-03

Engram v6.4.7 is a Codex plugin patch release for workstations where the
marketplace/plugin cache updates but the persistent plugin data binary remains
on an older version.

## What changed

- `ensure-binary.js` now verifies the actual client binary by running
  `engram --version` before trusting `bin/.version`.
- A stale plugin data binary now triggers a fresh download from the matching
  GitHub release asset.
- Regression tests cover the case where `bin/.version` claims the desired
  plugin version but the binary itself still reports an older daemon version.

## Upgrade note

After upgrading the marketplace snapshot and reinstalling the plugin, Codex
should create the `6.4.7` cache slot. On the first MCP startup, Engram may
download the fresh `v6.4.7` binary into plugin data before starting the MCP
daemon.
