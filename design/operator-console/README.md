# operator-console public design snapshot

This directory is the **public / tracked** contract snapshot for the Engram operator
console.

It is **not** the live OpenDesign workspace. The real authoring environment stays in
`.od/`, because OpenDesign works there. Stable material is promoted here intentionally.

See [PROMOTION-CONTRACT.md](./PROMOTION-CONTRACT.md) for the exact boundary between:

- `.od/` authoring
- `design/operator-console/` curated public contract
- `apps/operator-console/` tracked deployable source
