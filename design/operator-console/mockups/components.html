Переключатели

Чистый CSS, переключается через aria-checked. .danger — когда «включено» = опасно.

.toggle[aria-checked] / .toggle.dangerкликни — переключатели живые

<span class="toggle danger" role="switch" aria-checked="true"></span>

Settings Row

Вся поверхность настроек собрана из одной функции settingRow(title, desc, control): подпись слева, контрол справа.

Legacy-вход по админскому ключу

Запасной прямой вход в обход OAuth. Выключите, чтобы оставить только OAuth.

Вход через провайдера

Google, GitHub, Яндекс, VK, SSO. Базовый способ, отключить нельзя.

всегда включён
settingRow(title, desc, control)grid: копия | контрол
settingRow('Legacy-вход', 'Запасной вход в обход OAuth…',
  `<span class="toggle danger" role="switch" aria-checked="true"></span>`)

Login — провайдеры входа

OAuth/OIDC-кнопки, управляемые данными (AUTH_PROVIDERS + PROVIDER_MARK). SSO растягивается на всю ширину. Legacy-таб — отдельный запасной вход.

.ag-prov / .ag-prov.full · PROVIDER_MARK{}data-driven · добавь провайдера → кнопка появится
AUTH_PROVIDERS.map(p => `<button class="ag-prov${p.full?' full':''}" data-prov="${p.id}">
  ${PROVIDER_MARK[p.id]}<span>${p.name}</span></button>`)
// wiring → window.location = OAUTH_START[id] (см. PLAYBOOK §3.2)
