Политика доступа

Кто вообще может войти. Без этого правила любой аккаунт включённого провайдера (например, любой Google) получит вход. Для self-hosted это главный гейт.

Только по приглашению

Вход разрешён лишь тем, кого администратор пригласил по email. Самый строгий режим — рекомендуется по умолчанию.

Роли

Четыре уровня для self-hosted. Та же лестница масштабируется в SaaS: Owner/Admin воркспейса ложатся поверх платформенного Superadmin.

Owner
Владелец инсталляции. Полный контроль, включая провайдеров входа и роли. Назначается при установке, неудаляем.
1 чел.
Admin
Управляет пользователями, приглашениями и настройками консоли. Не может снять Owner.
1 чел.
Operator
Текущая рабочая роль: память, кандидаты, правила, задачи. Без доступа к управлению пользователями.
2 чел.
Viewer
Только чтение всех операционных поверхностей. Никаких мутаций.
1 чел.

В self-hosted роли фиксированы (преднабор). Кастомные роли с гранулярными правами — это уже SaaS-уровень, отдельным разделом.
