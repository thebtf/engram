Тарификация · Функции

Функции features

Функция (feature) — определение возможности: «что» умеет продукт. В плане каждая функция превращается в право (entitlement) — грант доступа с конкретным значением: 50 мест, 1M записей, вкл/выкл. Тип задаёт способ гейтинга: quota (число с лимитом), boolean (есть/нет), limit (порог). Из функций собираются планы в «Редакторе плана». Модель — как в Chargebee/Stripe Billing.

i
Функция → Право → План. Поле key функции — точка подключения в продукте: entitlement('memory.records') читает значение права из плана воркспейса. Функция — переиспользуемое определение; право — её привязка к плану со значением. Функции версионируются вместе с планом, в который входят.

Тарификация · План × Функция

Матрица «План × Функция»

Шаблон «функция доступна в таком-то плане». Ячейка задаёт значение feature-gate. Серая метка «override» — индивидуальное исключение для воркспейса (enterprise-сделка, grandfathering).

i
Один компонент feature-gate читает эту матрицу и внутри продукта рендерит «доступно / нужен апгрейд до плана X / квота исчерпана». Матрица — источник правды и для биллинга, и для гейтинга в UI.

Тарификация · Платежи и валюты

Платежи и валюты

Какими шлюзами платформа принимает оплату и в каких валютах выставляет счета. Глобальные провайдеры не работают с картами РФ — для рынка СНГ нужны локальные шлюзы и СБП. Провайдер выбирается под валюту/регион воркспейса автоматически.

i
Ключи всех провайдеров — write-only, reveal одноразовый. Режим test/live переключается на провайдере. Воркспейсу платёж маршрутизируется по его валюте: ₽ → локальный шлюз/СБП, $/€ → глобальный.

Сервис · Модели и доступы LLM

Модели и доступы LLM service-wide

LLM-эндпойнты подключаются один раз на всю платформу, а не на воркспейс. Здесь — все доступы (провайдеры, API base, ключи) и привязка ролей Engram к моделям, общие для сервиса.

i
В self-hosted эти настройки живут в консоли оператора (одна инсталляция). В SaaS они поднимаются на уровень платформы: один пул доступов обслуживает все воркспейсы. Подбор модели на воркспейс (если включён планом) ложится поверх этого пула.
