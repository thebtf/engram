ENG-MPL-1 / CR-003 Forgetting Consolidation

Running Decisions

T001 taxonomy contract

Decision: expose suppress, expire, archive, consolidate, and destroy as first-class public contract values in the cognitive package, with documentation that names semantics, policy boundaries, and audit surface.

Load-bearing claim: the taxonomy is not a disguised boolean delete path. Evidence will be contract tests, Prove-It failure against a broken contract, and the documentation contract.

Status: Aligned.

T002 classification service

Decision: implement a bounded classification service that returns decisions and audit/review metadata without mutating storage, using candidate/snapshot/audit language before adding packet routing.

Load-bearing claim: low-value, duplicate, stale, archive, and risky cases classify into five operations without data destruction by default. Evidence will be classification tests and G001 suite output.

Status: Aligned.

T003 structural-loss guard

Decision: represent structural loss as unique meaning, provenance, and scope dimensions in the classifier request/decision and force consolidation to review or destructive removal to block when loss is present.

Load-bearing claim: risky merge/destruction cannot silently collapse meaning. Evidence is structural-loss fixtures plus Prove-It failure when the guard is disabled.

Status: Aligned.

T004 risky review packets

Decision: emit bounded forgetting_review packets only for review-required or blocked decisions; safe suppress/expire/archive decisions remain auto-resolvable with audit.

Load-bearing claim: packets reuse snapshot/audit seams and stay bounded. Evidence is packet tests asserting capped evidence, memory ids, and bulk_op_snapshots/audit_log.

Status: Aligned.

T005 audit/export proof

Decision: close CR-003 with a proof artifact that names evidence, audit/export surfaces, blocked execution paths, and the temporal-truth boundary.

Load-bearing claim: high-risk forgetting paths are reviewable and exportable as evidence artifacts, while destructive execution remains blocked.

Status: Aligned.
