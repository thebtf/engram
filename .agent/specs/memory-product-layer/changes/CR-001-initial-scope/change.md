# CR-001: Initial Scope

## Delta

Create the first executable implementation slice for Agent Knowledge and Experience Layer:
- native state plane,
- principal explorer groundwork + principal-scoped brief path,
- minimal principal-memory UI delivery only where a reviewed designer contract exists,
- backend packet-centric review-loop substrate,
- designer-contract gate artifacts for implied later operator-facing UI.

## Rationale

The feature contract is aligned. The correct first CR is the smallest high-value slice that reduces resume cost, makes principal knowledge inspectable, and establishes packet-centric governance without pretending later experience/forgetting/temporal slices are already in scope.

## Acceptance

- [ ] `changes/CR-001-initial-scope/tasks.md` exists and is the active task list for this CR.
- [ ] Native state plane work is sequenced before principal explorer and review-loop substrate.
- [ ] Principal explorer work is treated as must-build substrate on top of existing privacy visibility, not as a completed PMQ/domain-registry extension.
- [ ] Minimal principal-memory UI delivery is allowed only on approved designer contract and honest live seams.
- [ ] Review-loop backend reuses existing candidate/snapshot/audit seams before any governance rebuild.
- [ ] Review-loop UI stays out of CR-001 unless a later CR explicitly expands scope.
- [ ] Any implied UI work is blocked on a designer-owned contract with wiring map and scenario proof.
