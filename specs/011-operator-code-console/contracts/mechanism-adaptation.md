Engram’s MIT license is not a license decision to copy either reference.

Neither label is a benchmark transfer.

## Gates, Comparison, and Rejections

The matrix above is the **current-slice mechanism gate** for S2: the exact R-A candidate must declare the bounded Go and TS/TSX relation fixture it can prove, preserve retrieval/coverage/View limits, and execute the A/B watcher scenario. It does not require a new reference-research program or broader comparator before S2.

The **broader R-C gate** is separate: any new language/relation, resolver behavior beyond the bounded fixture, reference-parity, or quality claim requires a source-oracle task set (exact identifier, RU concept, dependency, reverse impact, worktree switch, no-answer), aligned corpus/ignore/profile evidence, lexical baseline, and an independent judge. A missing optional comparator is `parity_not_checked`, not a defect or a parity claim. Graphify author benchmark numbers are stale author claims and are never transferred to Engram.

All agent and browser results remain one authorized Source/Checkout/View model. No corpus is sent to an unapproved provider. This contract neither changes accepted UCI core behavior nor chooses a parser, vector provider, graph algorithm, reference integration, or new product scope.
