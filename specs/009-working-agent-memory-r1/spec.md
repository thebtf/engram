**Status:** In implementation

## Outcome

A fresh installed OMP session receives one bounded authorized experience reference and, when applicable, one current issue before its first substantial action. After meaningful work, the agent may capture one portable lesson through the existing authorized memory write tool. A later independent session reuses that lesson without a manual recall request.

The normative product requirements are `01-PRODUCT-SPEC.md` in the authority package. The deliberate changes from the previous HAP sequence are `02-DECISIONS-AND-SCOPE.md`. This feature does not duplicate those documents.
